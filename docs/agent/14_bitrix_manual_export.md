# Bitrix Manual Export

Current production acquisition remains manual.

1. Open `https://andradealvesadvogados.bitrix24.com.br/crm/deal/category/9/`
2. Choose **Lista**
3. Click **Pesquisa**
4. Open **Fase do negócio**
5. Select **EM QUALIFICAÇÃO** or **QUALIFICADO**
6. Click blue **Pesquisar** at bottom
7. Click gear
8. **Exportar Negócios para CSV**
9. Select **Exportar todos os campos do negócio**
10. **EXECUTAR**
11. Wait for generation
12. **BAIXAR ARQUIVO DE EXPORTAÇÃO**
13. Upload to corresponding Streamlit field

Historical Playwright prototypes encoded this flow and a phase parameter, but are paused.
