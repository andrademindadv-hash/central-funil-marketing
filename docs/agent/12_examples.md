# Examples of Expected Judgment

**"Move to PostgreSQL."**
First verify whether Sheets is causing a real volume/concurrency/reliability issue. If not, keep the simpler stack.

**"Critical should obviously be before Limiar."**
Do not change automatically. Explain severity vs operational priority; 6d is intentionally preventive.

**"Add temperature back."**
Recognize that temperature/recency/score was explored and explicitly removed. Ask whether the user is reopening that decision.

**"Upload both phases together."**
Preserve separate validation/storage/dashboard. If true atomicity is required, identify current partial-publish risk and propose a batch backend action.

**"Automate Bitrix now."**
Recognize manual export is active and Playwright is paused. If explicitly reopened, reuse learned flow: direct category URL → Lista → Pesquisa → Fase do negócio → phase → Pesquisar → gear → Exportar Negócios para CSV → export all fields → Executar → download.

**"Make it prettier."**
Improve hierarchy, spacing, typography and storytelling before adding decorative complexity; preserve native KPI reliability.

**"Same-day history created two rows."**
Treat as a bug: same phase + same date must replace snapshot.

**"IDs are visible without password."**
Treat as a real security concern; admin upload password does not equal viewer authentication.
